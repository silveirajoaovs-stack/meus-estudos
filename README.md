# Meus Estudos · ADS

Site pessoal para acompanhar os estudos do curso de Análise e Desenvolvimento de Sistemas: matérias, progresso, resumos de aula, calendário e Pomodoro.

Feito com React + Vite + TypeScript, com dados e login no Supabase.

## Rodar no computador

1. Instale as dependências: `npm install`
2. Copie `.env.example` para `.env.local` e preencha com a URL e a Publishable key do Supabase
3. Inicie: `npm run dev` e abra http://localhost:5173
